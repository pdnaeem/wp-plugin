== Description ==
TrackPulse adds shipment tracking fields to WooCommerce orders, customer tracking shortcodes, and WhatsApp notifications with Cloud API support.

== Installation ==
1. Upload the plugin folder to /wp-content/plugins/.
2. Activate the plugin.
3. Configure settings under TrackPulse → Settings.
