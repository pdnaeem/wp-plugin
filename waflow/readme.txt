WAFlow adds a WhatsApp chat widget, captures leads, and powers lightweight CRM automations inside WordPress.

== Description ==
WAFlow provides a modern WhatsApp chat widget, mini CRM for contacts, and automation workflows triggered by forms and WooCommerce events.

== Installation ==
1. Upload the `waflow` folder to `/wp-content/plugins/`.
2. Activate WAFlow through the Plugins menu.
3. Complete the setup wizard and configure settings.
